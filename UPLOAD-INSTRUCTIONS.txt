OpalDay v1.2.0 — comprehensive recurrence and editing update

DATA SAFETY
This release keeps the existing local-storage key (opalday-data-v1), sync-code
key, Cloudflare D1 database, sync endpoint, calendar IDs, item IDs, event IDs,
completion history, reminder settings, visibility settings, and deletion
tombstones unchanged.

Existing event recurrence fields remain supported. New recurrence details are
stored alongside the legacy recurrence value, so this is a forward-compatible
extension rather than a destructive data rewrite.

GITHUB PAGES
Upload all files from this BUILD_OpalDay_v1.2.0 folder to the root of the
OpalDay repository, replacing files with the same names. The package is
complete: it includes the base styles, calendar styles, config, manifest,
service worker, scripts, and all icon sizes.

Keep cloudflare-worker-v0.10.0 as a reference folder. GitHub Pages will not use
the Worker file directly.

CLOUDFLARE WORKER
Open cloudflare-worker-v0.10.0/worker.js, copy the entire file, replace the
current Cloudflare Worker code, and deploy it. This update teaches scheduled
notifications the same custom recurrence and occurrence-count rules as the app.

No SQL migration is required. Do not recreate or replace the D1 database.

VERIFY
1. The Worker /health URL reports version 0.10.0 and recurringEvents "advanced".
2. Settings > About reports app version 1.2.0.
3. Create a harmless test event using Custom > every 2 weeks and verify the
   selected Sunday-first weekday controls and ending options.
4. Edit the test event and confirm it updates in place, then delete it.

ICON NOTE
The finalized supplied icon is included as 1024, 512, 192, and 180 px PNGs and
referenced by the manifest, browser icon, Apple touch icon, service worker, and
notification icon. iOS may retain an older Home Screen icon until OpalDay is
removed from the Home Screen and added again.
